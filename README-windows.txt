Voxel v0.1.0 — Windows x64
============================

Requirements:
  - 64-bit Windows 10 or later
  - GPU driver with Vulkan 1.2+ (Vulkan 1.2 is required by the engine)
  - Unzip the archive so voxel_desktop.exe, data/, shaders/, and assets/ stay in the same folder

Quick start:
  voxel_desktop.exe --scene terrain --width 1280 --height 720

See docs/release-notes-v0.1.0.md (included in the GitHub release) for controls, CLI flags, and known limitations.
